# multimedia-proje# 🚀 Interactive Multimedia Hub (BCA Minor Project)

A feature-rich, responsive web-based multimedia application built as a minor project for Bachelor of Computer Applications (BCA). This project integrates multiple core multimedia elements—including a custom video/audio player, an interactive lightbox image gallery, and a real-time HTML5 Canvas animation—into a single modern dashboard.

---

## 🛠️ Tech Stack Used

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
* **Styling & UI:** CSS Flexbox, Grid, Google Fonts
* **Icons:** FontAwesome 6.4.0
* **Multimedia & Graphics:** HTML5 `<video>`, `<audio>`, and `<canvas>` API
